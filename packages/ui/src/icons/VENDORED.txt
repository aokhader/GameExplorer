What was taken
--------------
For each name in paths.ts: the `d` attribute of the single <path> in
package/assets/regular/<name>.svg, or package/assets/fill/<name>.svg for a
name ending in `-fill`. Every such file is one path on a 0 0 256 256 viewBox.
The SVG wrapper is not kept; the path data is not modified.

How to add an icon
------------------
1. npm pack @phosphor-icons/core@2.1.1 into a scratch directory and extract it.
2. Confirm the SVG still holds exactly one <path> on the 256 viewBox.
3. Add the name to both `IconName` and `ICON_PATHS` in paths.ts, keeping the
   list sorted, with the path copied verbatim.
A new package version means updating every field above, not just the path.
